# Operation Heart Doom

A short English Ren'Py dating sim. One romance route: Zim.

Zim and Gir are original characters. Zim's sprites are your Paint drawings; Gir's sprite comes when you draw him.

## How to play

1. Double-click `launch.bat`, or
2. Open `C:\Users\User\Documents\renpy-8.5.3-sdk\renpy.exe`
3. Set the projects folder to `C:\Users\User\Documents` if the launcher does not see the game
4. Select **ZimsHeartConquest** and click Launch

## How it works

- You are an adult neighbor (18+)
- 7 days, map of 4 locations, affection meter
- Endings: True (16+), Alliance (8+), Abandoned (below 8)
